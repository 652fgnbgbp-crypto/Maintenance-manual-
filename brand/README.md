# Vantage logo files

| File | Use |
|---|---|
| `vantage-mark.svg` / `-1024.png` / `-512.png` | App icon, social avatar, favicon: white V and gold triangle on the navy tile |
| `vantage-v-white.svg` / `-1024.png` | The V alone, for dark or navy backgrounds |
| `vantage-v-navy.svg` / `-1024.png` | The V alone, for white or light backgrounds |
| `vantage-lockup-dark.svg` / `-2460.png` | Logo with "Vantage · By Torwood Aerospace Group", for dark backgrounds |
| `vantage-lockup-light.svg` / `-2460.png` | The same, for light backgrounds |
| `vantage-logo-sheet.png` | Preview of every version |

SVG files scale to any size; use them for print and the web. PNGs have transparent backgrounds.
The lockup SVGs use the Inter typeface. If Inter isn't installed where you open them, use the PNGs,
or convert the text to outlines in a design program before sending to a printer.

Colours: navy `#162943`, tile `#20395c`, Torwood gold `#dea652`, white `#ffffff`.
